Our small frame patches, 2026-10-11:
1. index.html: viewport, local-resource CSP, original title, start/restart,
   touch controls, compact status, debug options and same-frame legal/ link.
2. style.css: responsive aspect-preserving shell using the original local font
   and colours, with reachable touch controls in both orientations. Fix round 2
   gives shell buttons and Legal 44x44 minimum hit areas, reserves a 48px toolbar
   and wrapping options, and retains Legal in the lower-right corner. Compensating
   stage insets preserve canvas dimensions. Gameplay target rules are unchanged.
   Fix round 3 reserves Legal's bottom row in portrait and raises the touch rail,
   stage bottom inset and status by 32px. Transparent pseudo elements give rounded
   controls their full rectangular hit areas. Opening Controls hides the gameplay
   rail and welcome button until closing; its panel fits above Legal. Original
   game scripts, libraries, font, world dimensions and gameplay rules are retained.
3. scripts/main.js setup only: retain logical 600x750 geometry, cap density,
   show a paused start screen, call fitFrame. All rules and controls unchanged.
4. scripts/frame.js: fit on resize; cap logical and rendered pixel density at 2;
   translate move stick and buttons to the original p5 keyboard handlers;
   release held touch input on end/cancel/capture loss/blur/visibility loss.
5. legal/: full licences, attribution, source archives, data and dependency pins.
Proof and packaging tools are separate from the runtime.

p5-source.tgz supplies full preferred modules, build scripts, original package
lock, readable compiled library and the sources of its bundled dependencies.
The shipped minified library is unmodified and byte-identical to npm p5@0.6.0.
The generated docs/reference/data.json is extracted exactly from that npm
readable bundle. The original p5.dom.js is included for the core uglify task.
The optional documentation website and unrelated test fixtures are omitted.
After installing the original package's build dependencies, the core tasks are:
  npx grunt browserify browserify:min uglify
Original npm run build additionally invokes the omitted website build.
LGPL-2.1.txt accompanies it. Replace scripts/lib/p5.min.js with a compatible
modified p5 library, or point index.html to the readable local source extracted
from the archive. Reload in a static server to use your modified version.
There is no proprietary link step or prohibition on debugging modifications.
