CaveExpress corresponding source, free of charge on this origin

Download source.tgz from this directory. Together with ../caveexpress.data,
it contains all game code, editable Lua/map scripts, generated game assets,
linked dependency sources, Emscripten runtime sources, build instructions,
this page shell, patches and the rerunnable sandbox proof.
GPL version 3 section 6(d) permits object-code distribution when you
"offer equivalent access to the Corresponding Source in the same way through
the same place at no further charge". These files are provided together here.
This is source delivery under section 6(d), not a promise to provide it later.

Extract with: tar -xzf source.tgz
Restore all 349 data members and 12 pinned dependencies offline with:
  python3 source/prepare-source.py ../caveexpress.data
Activate an emsdk 4.0.5 compiler, then:
  bash source/build.sh ../caveexpress.data
See source/README-SOURCE.md for the build inputs and limits.
To recreate the page patches from the original loader:
  cd source/page
  python3 tools/patch-loader.py
To run the proof:
  npm ci --ignore-scripts
  CHROMIUM_PATH=/path/to/chrome bash proof/run.sh
